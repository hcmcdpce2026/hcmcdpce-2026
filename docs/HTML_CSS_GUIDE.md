# Quy chuẩn HTML/CSS

- Sử dụng HTML5 semantic: `header`, `nav`, `main`, `section`, `aside`, `footer`.
- Mọi control phải có `label` hoặc `aria-label`.
- Mọi ảnh phải có `alt` phù hợp.
- CSS toàn cục dùng Roboto qua `style.css`.
- Font Awesome 6 dùng cho icon.
- Đặt component Public/CMS/Workspace trong class prefix riêng.
- Không dùng height cố định để che phần chữ dư; dùng `-webkit-line-clamp`/ellipsis và lưới căn đều.
- Không thêm `!important` trừ khi có reason kỹ thuật đã xác nhận.
- Responsive kiểm tra mobile, tablet, laptop và desktop.
