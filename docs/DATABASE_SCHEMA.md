# Cấu trúc database

Database chính: `server/data/portal.sqlite`.

Nhóm bảng:

- users, roles, role_permissions, sessions, login_attempts.
- articles, categories, article_revisions, media, media_folders/system_categories.
- legal_documents, public_agencies, public_events, support_facilities, statistics_periods/items.
- submissions, submission_events, notifications.
- tasks, task_items, task_comments, task_history.
- reports, reports_documents, proposals, collaboration_requests.
- documents/doc_versions, organizations, activity_logs.
